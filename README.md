<a id="faq"></a>

## ❓ 机场与 VPN 套餐常见问题

### 第一次购买应该选月付还是年付？

优先用月付或小流量方案检查本地线路、常用节点和设备兼容。年付应同时比较总预付款、退款条款和流量规则，不能只看折算月价。[月付选择指南](https://noderadar.online/guides/monthly-airport/)

### 便宜机场主要比较哪些项目？

比较实际付款周期、可用流量、节点倍率、在线设备数与常用地区。体验包、年付折算价和月付价应分开看；例如魔戒榜单展示的是 ¥19.9/130GB 常规一次性流量包。[低预算选择指南](https://noderadar.online/guides/cheap-airport/)

### 不限时流量适合谁，会每月清零吗？

适合使用频率不固定或需要备用订阅的人，通常按总流量用完为止。账户有效期、叠加规则与重置费用仍要看服务条款；“不限时”不代表服务商永久运营。[按量与不限时指南](https://noderadar.online/guides/pay-as-you-go/)

### 节点倍率会怎样影响流量？

若节点为 2 倍倍率，实际传输 10GB 通常会扣除 20GB 套餐流量。比较套餐时应把倍率与常用节点一起核对，具体扣费规则以服务商说明为准。[节点倍率计算](https://noderadar.online/guides/traffic-multiplier/)

### 手机和电脑可以同时使用同一个订阅吗？

取决于套餐的在线设备数、在线 IP、连接数和客户端限制。例如 WgetCloud 同时列有在线 IP 与连接数限制，自由猫还有指定客户端和地区限制，不能把所有服务都理解为不限设备。

### “支持 ChatGPT 或 Netflix”代表所有节点都能用吗？

服务商的解锁说明不代表所有节点在所有时段都可用。购买后应使用自己常用地区的节点实际验证；单次成功不能作为长期表现的保证。[AI 工具与节点选择](https://noderadar.online/guides/chatgpt-vpn/)

### 机场测评与套餐对比应该看哪些证据？

套餐对比看价格、流量、付款周期和限制；速度与解锁测评还应提供测试日期、地区、运营商、节点、客户端和原始结果。服务商宣传、公开监测和维护者实际测试应分别注明来源。

## 📊 推荐指数与资料来源

综合推荐指数是 **10 分制编辑评分**，按价格与流量、计费灵活性、线路与设备、解锁与售后、限制项和资料完整度整理，用于比较现有方案。首页按需求计算的专项指数与综合评分不同。

评分不是统一地区、运营商和时段下的测速排名，也不是对速度、解锁或持续运营的保证。套餐与节点能力以公开页面说明为依据；公开监测资料缺少完整采集条件时，不作为当前实测结论。未来补充测试时，应同时记录环境、时段、节点、截图及失败样本。
